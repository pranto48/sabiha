# Sabiha Art Gallery

A colourful, single-page portfolio for Sabiha — a 13-year-old art explorer from Ashulia, Dhaka.
The site highlights her biography, photo art gallery, print shop, and playful 3D-inspired effects.

## Getting started

1. Open `index.html` directly in your browser or serve it via any static host (GitHub Pages, Netlify).
2. Customize the gallery cards, shop items, and biography text with Sabiha's latest work.
3. Update the image URLs with your own photos for the best experience.

## Features

- Animated hero section with glassmorphism cards.
- Life history timeline and storytelling sections.
- Gallery grid with hover tilt and floating organic shapes.
- Shop section for photo prints and digital downloads.
- Contact form ready for Netlify or static host integrations.

Enjoy celebrating Sabiha's creativity!
